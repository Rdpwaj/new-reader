# قارئ الفصول

تطبيق أندرويد للقراءة وتنظيم الفصول، مبني بـ Kotlin وJetpack Compose. تُحفظ الروايات والفصول والملاحظات والقاموس ومواضع القراءة محليًا على الهاتف.

## بناء APK عبر GitHub

المشروع يحتوي على GitHub Actions لبناء APK ونشره في **Releases**. ارفع محتويات هذا المجلد إلى مستودع GitHub، ثم جهّز مفتاح التوقيع قبل تشغيل البناء.

### مفتاح التوقيع والتحديثات

يبقى اسم الحزمة كما هو: `com.aistudio.chapterreader.qrfslx`. قاعدة البيانات لا تُحذف عند التحديث، لكن أندرويد يسمح بالتحديث فوق التطبيق فقط إذا كان توقيع النسخة الجديدة مطابقًا لتوقيع النسخة المثبتة.

1. إذا كان لديك ملف مفتاح التوقيع المستخدم للتطبيق الحالي، حوّله إلى نص Base64. على جهاز فيه `keytool` و`base64`:
   ```sh
   base64 debug.keystore | tr -d '\n'
   ```
   إذا لم يكن لديك المفتاح القديم، أنشئ مفتاحًا ثابتًا جديدًا مرة واحدة بعد حفظ نسخة JSON من التطبيق الحالي:
   ```sh
   keytool -genkeypair -v -keystore debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
   base64 debug.keystore | tr -d '\n'
   ```
2. في GitHub افتح **Settings → Secrets and variables → Actions → New repository secret**.
3. سمِّ السر `ANDROID_DEBUG_KEYSTORE_BASE64`، وضع فيه ناتج الأمر. لا ترفع ملف المفتاح إلى المستودع ولا ترسله في المحادثة.
4. افتح **Actions → Build & Release Android APK → Run workflow**. عند نجاح البناء سيظهر ملف APK في **Releases**.

يتوقف البناء برسالة واضحة إذا لم يُضف المفتاح؛ لا ينشئ مفتاحًا عشوائيًا جديدًا في كل مرة، لأن ذلك قد يمنع تثبيت التحديثات القادمة.

### إذا لم يتوفر المفتاح القديم

قبل حذف التطبيق الحالي، افتح **الإعدادات → النسخ الاحتياطي → نسخ احتياطي (JSON)** واحفظ الملف خارج التطبيق. بعد ذلك احذف النسخة القديمة، ثبّت APK الجديد، ثم اختر **استعادة نسخة**. للمستقبل استخدم المفتاح نفسه في سر GitHub حتى تُثبّت التحديثات فوق التطبيق من دون حذف البيانات.

## ما تغيّر في الإصدار 1.2

- تبسيط التنقل وإزالة شاشة الإحصائيات.
- إخفاء أعداد الكلمات وأوقات القراءة؛ بقي تقدّم كل فصل فقط.
- نقل حساب تقسيم النصوص الكبيرة إلى الخلفية لتخفيف التقطيع أثناء الكتابة.
- الحفاظ على اسم الحزمة وبنية قاعدة البيانات لتجنّب حذف بيانات المستخدم.
